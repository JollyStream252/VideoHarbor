# VideoHarbor
VideoHarbor, a Windows desktop downloader powered by yt-dlp.  It includes the workflow you requested: - Paste multiple links and click Analyze. - View each video's title, duration, thumbnail, estimated file size, and website. - Choose video quality from 360p through 4K, best available, or MP3 audio. - Select the destination folder. - Download all videos or only selected items. - Automatically create folders using playlist titles, falling back to website names. - Choose whether individual videos go into website-named folders or folders named after their video pages. - Monitor download progress and stop a batch. The application runs locally on your computer, without a subscription or added advertisements.
